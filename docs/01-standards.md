# Crown — Стандарты

Правило отбора: **только машинно- или тестово-проверяемое.** Вкусовое — не стандарт. Именование,
термины, комментарии — в `CLAUDE.md`. Архитектура — `00-architecture.md`.

---

## Границы (проверяются CI, не ревью)

| Граница | Как заявлена | Как проверена |
|---|---|---|
| `reduce` не делает I/O | zero-dep | `cargo tree -p crown-reduce` — один крейт |
| `reduce` не знает ICP/чейнов | zero-dep | `grep -rE 'ic_cdk\|std::(fs\|net\|time)\|reqwest' reduce/src/` пусто |
| Единственный не-`query` индекса — платный `ingest` | `.did` | парсер `.did` падает на любом другом не-`query` |
| Единственный не-`query` релея — `submit` | `.did` | парсер `.did` |
| Игра: фиксированный список `update` | `.did` | diff `.did` против `docs/spec.md §Методы` — **CI-джобы пока нет** (сверяется вручную) |
| Дорогая работа — только после оплаты/пруфа | порядок в коде | тест: неоплаченный вызов не делает outcall/подпись/запись |
| Игры не ходят наружу | нет SOL RPC-клиента, нет звонка в индекс | `grep` по `http_request` и inter-canister к индексу пусто |
| Нет таймеров/поллинга | нет `canister_global_timer`/`set_timer` | `grep` пусто |
| Ленивое создание | `create_*` не пишет | тест: `create` без пруфа рождения не растит стабильную память |
| Индекс не знает комиссий | в конфиге нет комиссий/казны | схема конфига |
| Сплиттер не владеет средствами | один прямой перевод | тест `zero_balance`: скан всего пространства аккаунтов — после расчёта ни одного нового token account, сумма сохранена, ни один не подчинён программе/её PDA |
| Репутация ≤ реально сдвинутых денег | сплиттер ревертит самосеттлмент | тест `self_settlement_reverts`: `ATA получателя == ATA донора` — не успешный no-op с событием (сверка индексатора этого не ловит) |
| Граница индекса fail-closed | `inspect_message` не зовёт `accept_message` ни на одном методе | тест: `ingest` и любой `query`, поданные ingress'ом, отбиты, баланс канистры не изменился |
| Индексатор не доверяет одиночному RPC | `RpcSources` — **одна** ветка `Default(cluster)`, поля `source` в конфиге нет | тип, а не линт: `Custom` не выразим |
| Флор выровнен | игровой `MIN_GROSS[game]` ≥ индексного `MIN_GROSS`; механизм есть во всех трёх играх (P6.6) | **не тестом, а cost-gate** (`07-build-plan §P8`): проверка живёт в репе игры, а индексный флор — в чужом, поэтому тест мог сравнивать его только с литералом-копией и не мог покраснеть при подъёме оригинала (`P7.13`). Build-зависимость на чужой конфиг не заводим — репы независимы by design |

Зависимости строго `crown-indexer → crown-reduce`; обратной нет.

## Код

- **`crown-reduce`:** `#![forbid(unsafe_code)]`; `#![deny(clippy::unwrap_used, expect_used, panic,
  arithmetic_side_effects, indexing_slicing)]`; только `checked_*`; исчерпывающие `match`, без `_ =>`
  на доменных enum; ошибка — значение, не паника.
- **Канистры:** `clippy` без предупреждений; `unwrap`/`expect` запрещены на горячем пути, в `#[init]`
  допустимы (паника = несостоявшийся деплой); арифметика циклов — `saturating_*`.
- **Программы (Solana):** максимально мало логики; Anchor; `transfer_checked`; никаких `unchecked`
  аккаунтов; денежная арифметика — `checked_*`/`.ok_or`, ревертит, не паникует.
- **Общее:** у каждой строки текущий потребитель; ни мёртвого кода, ни обобщённости «на будущее»,
  ни фича-флагов.

## Тесты, без которых этап не закрывается

1. **Закон репутации:** монотонность, аддитивность, пересчёт, изоляция ключа, детерминизм.
2. **Сплиттер:** `out == in`, нулевой донат ревертится, самосеттлмент ревертится, донор структурен,
   ноль баланса.
3. **Признание:** `Settled` не от пиннутого сплиттера не засчитан; атрибуция только от пиннутой фабрики.
4. **Оплата:** неоплаченный/недоплаченный `ingest`/`submit`/`request_signature` не делает дорогой
   работы; на отказе после accept — без рефанда (fund-then-fail не дешевле работы).
5. **Exactly-once:** повторная впись не меняет книгу; пустая сигнатура **не** помечается applied.
6. **Перекрёстная сверка:** событие с исполненным переводом (gross/mint/authority); расхождение —
   не засчитано, инкремент аномалий.
7. **Пруфы:** свидетель книги/рождения проверяется локально чистым счётом; сертификат — против root
   key NNS.
8. **Ленивое создание:** без пруфа рождения — ноль записи; спам `create_*` не растит память.
9. **Без таймеров:** временные переходы — чистая функция, вычисляются лениво на чтении/вызове.
10. **Иммутабельность:** upgrade authority сожжён (программы); контроллер снят (индекс, на заморозке).
11. **Релей:** не-allowlisted не тратит и не меняет состояние; per-key бюджет ограничивает утёкший
    ключ; `inspect_message` отсекает чужих/переростков до исполнения.
12. **Не-отрицательность** (инварианты `cost.md §6`, тест на каждый):
    - **Впись:** outcall с кэпом `response_max_bytes`; раздутая tx не заставляет платить больше
      `INGEST_PRICE`. Соотношение `worst_case ≤ ATTACH_CYCLES ≤ INGEST_PRICE` проверяет `build.rs` —
      несогласованный конфиг **не компилируется** (индекс заморожен, править потом нечем).
    - **Граница:** любой меняющий состояние ingress доказывает применимость в `inspect_message`;
      обречённый — плохой пруф рождения/веса, не тот подписант, пере-кэп — **не доходит** до
      реплицируемого `update`. Голос: свидетель веса + порог `MIN_VOTE_WEIGHT`; рождение: пруф
      рождения. Сама проверка на границе обязана укладываться в бюджет `inspect_message`
      (200M инструкций): BLS-пары сертификата индекса в него не влезают, поэтому корень
      аутентифицируется отдельным платным `push_root`, а на границе остаётся обход хеш-дерева.
      Так во **всех** канистерных играх — выровнено `P6.6`, гейтом CI «BLS only on the paid
      push_root» в каждой (`games-harness.md` §6).
    - **Голос:** сертификация не на голос, а при подписи; стоимость голоса не растёт с состоянием (O(log n)).
    - **Голос:** дедуп `(scope, voter)` — один кошелёк одну область голосует один раз.
    - **Подпись:** повтор на уже подписанной области **бесплатен** — подпись отдаётся из хранилища
      (`get_signature` — `query`), `sign_with_schnorr` второй раз не зовётся; конкурентные запросы на
      одну область оплачивают её один раз (claim до `await`). Флор — статический
      `MIN_GROSS[game] ≥ be·(1+MARGIN)`, применяется при регистрации; динамического правила подписи
      нет (`cost.md §6`).
    - **Ретраи:** нечитаемая сигнатура **не** запоминается — провал удерживает оплату (тест 4), но
      состояния не меняет, и следующий вызывающий свернёт её. Бюджета попыток нет намеренно: он был бы
      само-лимитом в permissionless-коде (`00 §6`). Тест: сколько угодно провалов подряд не делают
      сигнатуру невписываемой.
    - **Утёкший ключ:** per-key бюджет считается **в циклах**, не в вызовах; `Sign` списывает свою
      реальную цену, суточное окно капит суммарный ущерб одного ключа.

Тесты лежат рядом с исходником, который проверяют.

## Конфиг

Единая `config/`. Ничего сетевого в коде. Два профиля: `testnet`, `mainnet`; смена среды = смена
профиля, ноль изменений кода.

- **Per-chain (индекс):** `id`, `consensus`, `splitter`, `usdc`, `factories` (список, ноль или более).
  Поля `source` нет и не будет: провайдеров выбирает SOL RPC-канистра, индекс всегда шлёт
  `Default(cluster)`.
- **Профиль-уровень (замораживаемые, пиннятся cost-gate):** `INGEST_PRICE`, `SIGN_PRICE` (пол оплаты
  подписи игр), `ROOT_PRICE` (пол оплаты пуша корня индекса в игру), `MIN_GROSS`, `CYCLE_FLOOR`,
  `ATTACH_CYCLES` (циклы, аттачимые к outcall'у индекса, ≤ `INGEST_PRICE`),
  `RESPONSE_MAX_BYTES` (кэп ответа RPC, инвариант не-отрицательности #1),
  `CUTOVER_SLOT` (граница поколения, `00 §8`;
  ноль = границы нет), а также входы модели стоимости outcall'а
  (`rpc_nodes`, `rpc_providers`, `rpc_request_bytes`) — по ним `build.rs` считает worst-case.
- **Игра:** `crown_index`, `threshold_key`, `sign_price`, `root_price`, тайминги профиля
  (`voting_period` и её собственные), `fee_bps`/`fee_wallet`, per-chain `id`/`factory`/`domain`;
  где применим слот→время — `slot_ms`/`genesis_slot`/`genesis_unix`.
- **Релей (управляемые, не замораживаются):** `INGEST_PRICE`, `SIGN_PRICE`, `ROOT_PRICE` — по цене на
  каждый вызов, который релей фронтит (`GameCall` закрыт типом); `DEAREST_CALL` = максимум из трёх,
  и `build.rs`/`config.rs` не дают собрать конфиг, где per-key бюджет не покрывает дорожайший вызов —
  иначе тот молча недостижим. Плюс `BURST_BUDGET_CYCLES`/`BURST_WINDOW_SECS` и
  `DAILY_BUDGET_CYCLES`/`DAILY_WINDOW_SECS` — per-key бюджет в циклах (инвариант #6). Релеер не
  заморожен: растёт объём — растут бюджеты, это управление, а не константа заморозки.
- **Нет и не появится:** RPC-URL, API-ключ, чьи-либо комиссии (в индексе), адрес казны,
  `finality_depth`, схема подписи, `Custom`-источники.
- Только нативный USDC (Circle); bridged/обёртки запрещены.
- **Флор:** игровой `MIN_GROSS[game]` ≥ индексного `MIN_GROSS`.
- Solana-репы держат сетевые значения в `deploy/{testnet,mainnet}.toml` (минт, сплиттер, DOMAIN
  форм) — то же правило, другая директория.

## Циклы

- Газ Solana — донор. Циклы канистр — оператор (reverse gas): читатель не платит никогда.
- Дорогой работы вне оплаты не существует по построению (нет неоплаченного DoS-вектора).
- Пополнение заблэкхоленной канистры — permissionless deposit; механизм пополнения (операционные
  средства → cycles) описан и протестирован **до** снятия контроллера (порядок необратим).
